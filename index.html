Comparing Rules-Based Search and Two LLM Approaches

Ask a Company Policy Question

Compare three approaches using the same question.

How the Methods Work

Rules-based search: Matches keywords against company policies without an LLM.

LLM without vector index: Sends the policy database and question to Gemini.

LLM with vector index: Uses TF-IDF retrieval to select relevant policies before asking Gemini.

Reliability note: A generated answer may be unsupported or incorrect. Verify answers against the original policy database. API errors and response times can vary between requests.
